\section{Run scripts}
Each version has a PowerShell and a Bash driver in the repository root that runs its unit tests (gates) first and then the analysis
scripts in order: \file{run\_all.ps1}/\file{.sh} (v1--v2), \file{run\_v3} \dots{} \file{run\_v13} (\file{.ps1} and \file{.sh}). The
version reports end with a ``re-run'' section listing the exact order, durations and download volumes; for example
\verb|./run_v4.sh test a burst b3 b2 b1| runs the v4 parts selectively. Scripts select their configuration block through the
environment variable \code{XRB\_VERSION} (\file{scripts/config.py}). Raw data outside the repository are found through
\code{XRB\_EXTERNAL\_RAW} (default \file{\textasciitilde/xrb-pilot-data/raw}).

\section{Data locations}
\begin{itemize}
\item \textbf{In git}: source tables, observation lists with every exclusion reason (\file{data/*/observations.csv}), processed feature
files (\file{features.npz}, \file{*\_features.csv}), all result tables (\file{results/}), figures and logs.
\item \textbf{Not in git} (\file{.gitignore}): raw RXTE products in \file{data/raw/} (v1--v3, v8 events), raw files of v4b1 and NICER prefixes,
tails and v13 cleaned files under \file{\textasciitilde/xrb-pilot-data/raw/}, 3C50 spectra under
\file{\textasciitilde/xrb-pilot-data/nicer\_bkg\_spectra/}, the NICER CALDB under \file{\textasciitilde/xrb-pilot-data/caldb/}. All can be
re-downloaded with the scripts; v11 streamed $\approx39$\,GB without storing the bytes.
\item \textbf{Download log}: \file{logs/downloads.jsonl} has one JSON record per downloaded or streamed file (50,777 lines at commit
\texttt{d9730c9}) with the fields \code{url}, \code{path}, \code{bytes}, \code{sha256} and \code{utc}, so every input can be verified
byte for byte after re-download.
\end{itemize}

\section{Environment}
\begin{itemize}
\item Python 3.12.10 (Windows, \file{logs/environment.txt}; re-checks on macOS with Python 3.12.14), with the versions pinned in
\file{requirements-lock.txt}: numpy 2.4.4, pandas 2.3.3, scipy 1.17.1, scikit-learn 1.8.0, astropy 7.2.0, matplotlib 3.10.9, joblib 1.6.0,
requests 2.33.1 (plus their dependencies); software references: scikit-learn \citep{Pedregosa2011}, NumPy \citep{Harris2020},
SciPy \citep{Virtanen2020}, Astropy \citep{Astropy2022}, Matplotlib \citep{Hunter2007}.
\item Second-machine check (decision log, 2026-09-30): on macOS the 2,689 v1--v2 raw files were re-downloaded from the URLs in
\file{logs/downloads.jsonl} with all SHA256 values matching; \file{features.npz} agreed with the Windows file to $\le10^{-16}$, LR scores were
identical, single RF scores differed by $\le0.006$ (source means $\le0.001$), and all predicted labels and accuracies were identical.
\item HEASoft 6.37.1 \citep{HEASoft2014} in WSL Ubuntu 22.04 for the XSPEC \citep{Arnaud1996} cross-check (v2), \code{nh} and XSPEC \code{tbabs} (v8d) and \code{nibackgen3C50} with
the NICER CALDB (v12, v13).
\end{itemize}

\begin{itemize}
\item Sources: \file{report\_en/main.tex} and \file{report\_en/sections/*.tex}; bibliography \file{report\_en/references.bib}.
\item Figures: repository figures copied unchanged to \file{report\_en/figures/} with their original sub-paths; new data figures G1--G5 are

inside the chapters; the flowcharts (the chain of questions, the six phase analysis maps, the processing pipelines and the
evaluation protocols) are TikZ files in \file{report\_en/figures/flowcharts/}, drawn with the shared \texttt{fc} styles of
\file{main.tex}.

\item Tables of per-source scores were generated from the committed CSV files by small read-only scripts; no model was refitted and no
statistic recomputed except where explicitly stated in the text (hard-like per-source means in \cref{tab:p4v8asrc}; the Mann--Whitney
check in \cref{sec:p5v9b}; the Spearman $\rho$ and label agreement printed in \cref{fig:p4rxtemaxi}, identical to the repository values).
