## 2. 資料與凍結管線
1. **選樣**（`60_v13_select.py`，已寫好）：66 個 v9 天體中，不在 v9 試過的 792 筆、也不在 v11 試過的 588 筆內的合格觀測。依時間分 8 段，每段以 `default_rng(SEED + 2000 + 位置)` 排序，最多試 3 筆。
2. **特徵**（`61_v13_fetch.py`，同 v11）：串流整個 cl 檔（≤ 1 GB），套用凍結的 `v9lib.obs_features`，品質規則同 v9。
3. **背景**（`62_v13_bkg.py`，同 v12）：2–10 keV < 500 c/s 者跑 3C50。
   - 修正：rms 乘上 1/(1 − f)；顏色用各能段的 f 修正。
   - 篩選：f > 0.20 或 3C50 失敗者排除。
   - 能態依修正後的 rms 判定。
   - 暗觀測額外保留 cl 檔，供 §5 的敏感度分析使用。
4. **凍結模型**：在 v12 修正篩選後的資料（`data/v12/processed/nicer_corrected_screened.csv`，534 筆）上擬合 H_N-RF、H_N+T_N-RF（以及 LR）。每個天體只用排除該天體的模型預測它的 v13 觀測（out-of-source）。
5. **健全性**（IC1）：v13 修正後，Z 源（Cyg X-2＋GX 17+2）≥ 2/3 為軟態類。另外，IC2：v13 觀測與 v9／v11 試過的觀測不重疊。

## 3. v13a ★：前瞻性的 RF 硬態時間增益
- v13 修正篩選後的硬態類，觀測層級 AUC：**凍結 H_N+T_N-RF − 凍結 H_N-RF**。
- 區間：在 v13 的全部天體上做 BH／NS 分層重抽（v7a 方式）。區間不含 0 → 有差異。
- 可檢定條件：BH、NS 天體各 ≥ 3。
- 描述性：LR 版本；軟態類；來源層級；凍結規則 ν* = 1.336 Hz 的敏感度與特異度。

## 4. v13b ★：前瞻性的特徵頻率差
- v13 修正篩選後的硬態類、ν_c 有值：log₁₀ ν_c 對標準化的修正後 [c1, c2] 做不看標籤的 kNN 殘差化（k = 25，留一天體）；D = BH − NS；天體標籤置換 20000 次，雙尾 p。
- p < 0.05 → 有差異。
- 描述性：不修正、不篩選的版本；逐一移除 BH 天體。

## 5. 描述性：只用 3C50 保留的時段
- 對有 3C50 結果的暗觀測：事件只保留落在 3C50 總能譜 GTI 內的部分，用同一個 `obs_features` 重算特徵，再重做 v13b（亮觀測維持不變）。用來檢查 v12 發現的「3C50 GTI 與時間特徵 GTI 不一致」是否影響結論。
