## 1. v3a：巢狀比較（硬度之外的增量資訊）

### 1.1 表示法（全部使用 v2 的 456 筆、31 個 LOSO folds）
- 重現檢查：A、B、H、HI 用 v2 相同程式邏輯重算，必須與 `results/v2/oof_predictions_loso.csv` 一致
  （LR 應逐位一致；RF 容許跨平台 ≤0.01 的單筆差異，Mac 重現紀錄曾見 ≤0.006）。
- **H+B**：[H 的兩個顏色, B 的 45 個形狀 bin]（47 維）。
- **HI+A**：[HI 的兩個顏色與 log10 F, A 的 45 個 asinh 強度 bin]（48 維）。

### 1.2 主要比較（事先宣告）
- **主問題**：H+B − H（LR 與 RF 各一）。指標：觀測層級 balanced accuracy、來源層級 balanced accuracy、來源層級 AUC。
- 次要：HI+A − HI。
- 判讀規則（事先寫定）：若 H+B − H 的 bootstrap 95% 區間包含 0 或在 0 以下，
  結論為「在此表示法下，未偵測到硬度以外的增量資訊」；區間完全 > 0 才說「有增量資訊」。
  這是「無法偵測」而非「證明不存在」：7 個 BH 限制了檢定力。

### 1.3 新增指標
- **來源層級 AUC**（不需門檻）：以各源平均 BH 分數對真實類別算 ROC AUC。對 A、B、H、HI、H+B、HI+A 全部報告，含 bootstrap 區間。
- 事後描述統計（**已在寫本文件前看過**，此處只是正式記錄，不作為檢定）：
  v2 的 B 與 H 逐筆 OOF 分數 Spearman ρ = 0.91（LR）/ 0.83（RF），預測標籤一致率 88% / 93%。
  v3a 會對 H+B 與 H 報告同樣的描述統計。

### 1.4 標題指標
- 因天體比 7:24，報告的一句話結論一律以 **來源層級 balanced accuracy 與 AUC** 為主，
  「分對 k/31」只作補充（全部判 NS 就有 24/31）。

## 2. v3b：3–25 keV 能段（本機執行）

- 樣本：v2 已接受的 456 筆觀測，同一組原始檔（`data/v2/observations.csv` 的 `path_src/path_bkg/path_rsp`），
  同一 deadtime 修正（該表的 `dcor` 欄），不重新下載、不重新篩選。
- 能量格點：以同一參考觀測 `91702-01-66-05` 的 EBOUNDS，取最接近 3.0 keV 與 25.0 keV 的通道邊界之間所有通道。
  重分箱、單位（count/s/keV/PCU）、背景扣除、誤差傳遞與 v2 完全相同（`spectra.py`）。
- 品質：每筆觀測若 EBOUNDS 不覆蓋新格點，或 3–5 keV 淨計數為非有限值，記錄並排除；
  不以結果為依據替換觀測。F(3–5) ≤ 0 的觀測保留（比值分母不使用 3–5 keV，見下）。
- 表示法：
  - **B3**：rate / F(3–25)。
  - **H3** = [F(3–5)/F(5–7), F(7–10)/F(5–7), F(16–25)/F(10–16)]：在 v2 的兩個顏色外加一個軟色。
    軟色把 3–5 keV 放在分子，分母只用 5–7、10–16 keV（v2 中全部 > 0），因此 F(3–5) ≤ 0 時比值仍有定義。
  - **H3+B3**。
  - 同時在**完全相同的觀測子集**上重算 v2 的 B 與 H，以便配對比較。
- 主要比較：B3 − B、H3 − H（加入 3–5 keV 是否有幫助）；H3+B3 − H3（3–25 keV 下是否有硬度以外的增量）。
- **已知風險（事先寫明）**：3–5 keV 對星際吸收 N_H 敏感，而 N_H 是視線方向性質、與天體身分綁定。
  因此 B3/H3 的任何提升都可能部分來自「認得天體的吸收」而非 BH/NS 物理。
  v3b 只報告結果並標註此混淆，不宣稱物理解釋；若要排除，需要逐源 N_H（未在本版蒐集）。

## 3. v3c：BH candidate（本機執行，需新下載）

- **候選清單（草稿，執行前必須由使用者對照 BlackCAT 網頁版逐一確認，確認後才凍結）**：
  BlackCAT 中「非動力學確認」的 BH transient／persistent candidates，且在 RXTE MissionLongData 有目錄檔者。
  草稿名單見 `scripts/config.py` 的 v3c 區塊；名單由記憶整理，**尚未逐一查證**。
  XTE J1908+094 列入時特別注意：它與 NS 4U 1907+097 相距約 0.4°，v2 的 0.1° 指向檢查必須保留（Garg+2026 的配對錯誤）。
- 觀測選取、品質規則、能量格點、特徵與 v2 相同（每源 15 筆時間分層，合格 < 10 筆的來源排除）。
- 分析 1（預測，非評估）：用 v2 的全部 31 個確認天體訓練（A、B、H、HI × LR、RF），預測每個 candidate；
  報告來源平均分數與觀測分數分布。**不計算任何正確率**，也不以此更改任何標籤。
- 分析 2（標籤敏感度）：LOSO 只輪流保留 31 個確認天體；訓練集 = 其餘確認天體 + 全部 candidates（標為 BH）。
  與 v2 相同 folds 的結果配對比較（BH recall、來源層級 balanced accuracy、AUC）。
  測試永遠只在確認天體上，candidate 標籤不進入評估。
- 風險：若 candidates 中混有 NS，分析 2 會把錯誤標籤帶進訓練；這正是此敏感度分析要量化的。
