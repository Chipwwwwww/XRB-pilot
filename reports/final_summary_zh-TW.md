# XRB-pilot 最終總結（v1–v13）：用 X 光能譜與時間變異分辨黑洞與中子星

日期：2026-10-06　｜　逐版細節：[final_report_zh-TW.md](final_report_zh-TW.md) §1–§19 與各版報告（`reports/report_v*_zh-TW.md`）　｜　所有決定與偏離：[decision_log.md](decision_log.md)
跨版本總結圖：`figures/final/summary_across_versions.png`；數值：`results/final_timing_gain_across_versions.csv`、`results/final_nuc_difference_across_versions.csv`

> **一句話結論**：
> - 單次觀測的 X 光**顏色**能在「訓練時沒見過的天體」上分辨 BH 與 NS。但能力幾乎全來自兩個硬度比，而且主要在**軟態**有效；硬態時 BH 與 NS 的顏色重疊（AUC 約 0.5–0.7）。
> - 加入 **0.016–4 Hz 的時間變異**後，硬態的分辨力穩定提升（AUC 約 +0.15 到 +0.25）。這在兩台儀器（RXTE、NICER）、跨儀器合併，以及**事先凍結、全新觀測**的前瞻性檢驗（v13：+0.18 [+0.05, +0.34]）都成立。
> - 在相同顏色下，BH 的低頻變異特徵頻率一直比 NS 低約 0.3–0.6 dex（2–4 倍）。合併檢定有差異（v10：p = 0.0012），但單一資料集常在顯著邊界上下。
> - **主要限制**：
>   - 動力學確認的 BH 只有 16 個天體，可用的已幾乎用盡；
>   - 所有「新資料」檢驗都是同一批天體的新觀測，**還沒有在新天體上確認**。

## 1. 研究問題與設計原則
- **問題**：只用一次 X 光觀測（能譜、時間變異），能不能分辨吸積的黑洞（BH）與中子星（NS）？而且是在訓練時沒見過的天體上。
- **標籤**：
  - BH 只用動力學確認者（BlackCAT；後來改用 Marcel+2026 Table 1）。
  - NS 用 type-I X 光爆發源（Galloway+2008、MINBAR）與脈衝星。
  - 不用「候選者」當標籤，候選者只做敏感度分析。
- **評估原則**（v4 起固定）：
  - 以天體為單位的 LOSO；
  - 來源分數＝OOF 平均；
  - 2000 次、BH／NS 分層的天體 bootstrap（seed 42）；
  - **95% 區間不含 0 才寫「有差異」**；
  - 每版只有一個或少數事先宣告的 primary；
  - 所有選擇都做巢狀處理；
  - 所有變更記錄在 decision_log，並標明是否在看過結果之後。
- **預先設定的時間點**：每一版的預先設定都寫於看過之前所有版本的結果之後，由我依使用者指示自行核准，在下載該版資料前提交到 GitHub。因此，越後面的版本，假說越受先前結果引導。v11–v13 用全新觀測與凍結管線部分彌補這一點。

## 4. 結論的三個層次

**證據充分**
1. 兩個 X 光顏色（硬度比）就涵蓋了能譜中幾乎所有 BH／NS 資訊；更多能段、更彈性的模型都沒有幫助（v1–v4、v8c）。
2. 顏色的分辨力集中在軟態；硬態時兩類重疊。只用顏色時的硬態 AUC：RXTE 0.65；NICER 各樣本 LR 0.50–0.68、RF 0.67–0.75。
3. 在硬態加入 0.016–4 Hz 的時間變異，分辨力提升：
   - 在 RXTE v2、NICER 三組不同觀測、跨儀器合併中都一致；
   - 在事先凍結的管線與模型下，全新觀測上也成立（v13 RF +0.18 [+0.05, +0.34]）；
   - 背景修正後仍成立（v12、v13）。

**有一致方向、但檢定力邊緣**
4. 在相同顏色下，BH 的低頻變異特徵頻率比 NS 低約 0.3–0.6 dex。
   - 每一份資料的點估計都是負的；外部 RXTE（4 個 BH）例外，接近 0。
   - 合併檢定有差異（v10，p = 0.0012），但單一 NICER 資料集的 p 在 0.02–0.21 之間。
   - 物理上與「特徵時標隨緻密星質量（或內盤半徑）增加」一致，但沒有控制 Eddington 比，無法分開質量與吸積狀態的影響。
5. 時間增益在非線性模型（RF）上比線性模型（LR）穩定：RF 每次約 +0.17 到 +0.25；LR 從 +0.06 到 +0.26 不等。

**沒有得到支持**
6. Sunyaev & Revnivtsev（2000）的「500 Hz 以上有雜訊 → NS」：扣除跨偵測器的假訊號後，以單次觀測的靈敏度幾乎偵測不到（v8c，探索性）。
7. MAXI 上用確認 BH 的嚴格流程時，LR 幾乎沒有分辨力；de Beurs+2022 的高正確率主要來自兩類 NS 的分離（v7c）。

## 5. 主要限制
1. **天體數**：動力學確認的 BH 只有 16 個天體在 RXTE／NICER 有可用資料；硬態類每台儀器約 7–9 個。Marcel+2026 名單中其餘 BH 沒有可用的計時資料。
2. **獨立性**：v11–v13 的「新資料」都是同一批天體的新觀測。要做天體層級的確認，需要新的 BH（未來的暫現源），或可以腳本取得的其他任務資料（Insight-HXMT／AstroSat 本次未能查證取得方式）。
3. **預先設定的時間點**：每版都寫於看過先前結果之後，越後面的版本越可能受先前結果引導。v13 以凍結管線與事先選定的 RF 處理這個問題。
4. **背景**：NICER 用 3C50 修正平均背景，但 2017–18 年以舊增益校正的觀測無法處理（約 28% 的暗觀測被排除）；也沒有處理背景的時間變化。
5. **沒有物理控制**：沒有控制 Eddington 比、傾角、距離；NS 樣本混合了 AMXP、Z 源、atoll 源等子類。

## 6. 若要繼續（可發表所需）
1. 把凍結的 RF（顏色＋0.016–4 Hz rms）與 ν_c 規則，用在**新的 BH 暫現源**與新 NS 上，做天體層級的前瞻性確認。
2. 整理各源的距離與質量，控制 Eddington 比，檢驗 ν_c 差異是否隨質量縮放。
3. NICER：用 SCORPEON 或重新處理舊增益校正的資料，救回被排除的觀測。
4. 正式的跨儀器、天體層級統合分析，並把 RF 的增益寫成可重現的分類工具（含 conformal 預測集，見 v6）。
