## 1. 做了什麼

### 1.1 設計
- **天體身分**：RXTE 與 NICER 的天體距離 ≤ 0.1° 視為同一個（34 對，標籤全部一致）。所有合併統計量都以**天體聯集**為抽樣／置換單位：86 個天體，其中 16 個 BH。
- **v10a**：三個子樣本各自算「硬態類觀測層級 AUC 的增益」，再等權平均。
  - RXTE v2：v5 的 H+T-LR 對 v2 的 H-LR；
  - RXTE 外部：v6 凍結模型；
  - NICER：整筆特徵、LOSO。
  - 區間用天體聯集做 BH／NS 分層重抽 2000 次；每次重抽在各子樣本內重算（v7a 方式）後平均。
- **v10b**：每台儀器分別做「不看標籤的顏色 kNN 殘差化」（同 v6d／v9b），取每個天體的平均殘差，D_inst = BH 平均 − NS 平均，D = 兩台平均。
  - 虛無分布：依「出現在哪台儀器」分層，在層內置換標籤 20000 次；同一天體在兩台儀器上是同一個標籤。
- **v10c**：v9 的 368 筆 NICER 觀測，從 v9 前段之後接著下載到檔尾（每筆最多 1 GB），共 24.2 GB。特徵管線不變，用所有有效段。

## 2. 結果

### 2.1 v10a：合併的硬態時間增益

| 子樣本 | 硬態類觀測 | BH／NS 天體 | 增益（H+T-LR − H-LR） |
|---|---|---|---|
| RXTE v2（v8a） | 180 | 7／17 | +0.264 [+0.044, +0.469] |
| RXTE 外部（v8b） | 99 | 5／15 | +0.064 [−0.171, +0.341] |
| NICER 整筆（新量測） | 144 | 7／32 | +0.107 [−0.010, +0.224] |
| **★ 合併（等權）** | | **聯集 86 源、16 BH** | **+0.145 [+0.028, +0.257]** |
| 合併（依 BH 天體數加權） | | | +0.154 [+0.041, +0.260] |
| RF：RXTE v2＋NICER | | | +0.224 [+0.108, +0.333] |
| 排除 13 筆背景可疑的 NICER 觀測 | | | +0.152 [+0.036, +0.263] |

- **逐一移除 BH 天體**（點估計）：合併增益在 +0.110 到 +0.158 之間。
  - 影響最大的是 XTE J1118+480（移除後 +0.110；它在 RXTE v2 從 0.41 被改到 0.94），其次是 GS 1354-64（移除後 +0.118）。
- NICER 改用整筆後是 +0.107，與 v9 前段的 +0.112 幾乎相同，而且仍然是單獨看時區間碰到 0。

### 2.2 v10b：合併的特徵頻率

| 分析 | 天體（BH） | D = BH − NS（log₁₀ ν_c，同顏色） | p |
|---|---|---|---|
| RXTE 硬態類（v2＋外部，Standard-1 ν_c 1/128–4 Hz） | 44（12） | −0.265 | 0.0018 |
| NICER 硬態類（整筆，1/128–64 Hz） | 39（7） | −0.471 | 0.033 |

- **逐一移除 BH 天體**：合併 D 在 −0.329（移除 GRS 1915+105）到 −0.420（移除 4U 1543-47）之間。
- NICER 單獨看，從 v9 前段的 p = 0.136（−0.31）變成整筆的 p = 0.033（−0.47）。資料變多（段數加倍）之後，效應變得更清楚。

### 2.3 v10c：NICER 整筆的量測品質
- 每筆的 128 s 段數中位數 9 → 16。
- 與 v9 前段的一致性（Spearman）：T1 0.915、T2 0.948、T3 0.961、0.1–10 Hz rms 0.968、ν_c 0.932。
- 整筆資料的 split-half 信度（Spearman-Brown）：T1 0.81、T2 0.89、T3 0.81、rms 0.86、ν_c 0.89。
- 能態判定改變的有 9/368 筆。

## 3. 解讀

**數據直接支持**
1. 在兩台儀器、16 個動力學確認 BH 與 70 個 NS 的聯集上，加入 0.016–4 Hz 的時間變異後，硬態類的 BH／NS 分辨能力（觀測層級 AUC）平均提升約 0.15，區間不含 0。這不靠任何單一 BH 天體。
2. 在相同的 X 光顏色下，BH 的低頻變異特徵頻率比 NS 約低 2.3 倍（−0.37 dex），兩台儀器各自都是負值，合併 p = 0.0012。這不靠任何單一 BH 天體。
3. RF 的合併增益（+0.22）比 LR 大，顯示時間特徵和顏色之間有非線性的交互作用。
4. NICER 的時間特徵在獨立的一半資料間有 0.8–0.9 的信度，量測本身是穩定的。

**可能解釋（未驗證）**
- 「BH 的特徵頻率較低」與「特徵時標隨緻密星質量（或內盤半徑）增加而變長」的圖像一致：BH 約 5–20 M☉，NS 約 1.4 M☉。但效應只有約 2.3 倍，小於質量比，也可能受吸積率／光度不同的影響。本研究沒有控制 Eddington 比。
- 硬態內的時間增益，主要來自 BH 在相同顏色下有較強、頻率較低的低頻變異。這和 v6d／v9b 的特徵頻率結果是一致的兩個面向。
- 外部 RXTE 子樣本的增益最小（+0.06），可能是因為外部 NS 以 AMXP 為主，其中 IGR J00291+5934 的低頻變異很強。

**需要更多資料的假說**
- **真正獨立的確認**：在本專案從未使用過的天體與儀器上，例如 Insight-HXMT、AstroSat，或 NICER 未來的新暫現 BH，用**凍結**的特徵定義與門檻做前瞻性檢驗。
- 以 Eddington 比控制光度，分開「質量」與「吸積狀態」對 ν_c 的影響；並用 Lorentzian 擬合取得真正的特徵頻率，而不是 νPν 質心。
- 把這兩個特徵寫成可用的分類規則（例如「硬態且 ν_c < 1 Hz → 偏 BH」），在新天體上評估。

## 4. 限制
1. **不是獨立確認**：假說來自 v5–v9；RXTE v2、RXTE 外部、NICER 前段的結果都已看過，只有 NICER 整筆是新的量測（觀測本身相同）。合併方式（等權平均、天體聯集）在預先設定中寫定，但是在看過各子樣本結果之後才寫的。
2. 置換方式在建模前由「聯集整體置換」改為「依儀器出現情形分層置換」，依據是合成檢定力測試，已記錄。
3. BH 天體仍少（合併 16 個，硬態類每台約 7 個）。天體在兩台儀器間的重疊雖已用聯集處理，但年代與狀態不同。
4. RXTE 與 NICER 的能段、ν_c 頻寬不同，D 雖都以 dex 表示，但不完全可比。
5. NICER 仍未扣背景，只做了排除背景可疑觀測的敏感度分析（結果不變）；12 筆亮源在 1 GB 截斷。
6. Bootstrap 與置換都固定 OOF 預測與特徵，不含模型擬合的變異。

## 5. 與預先設定的差異（全部記在 decision_log）
1. **置換方式**（建模前）：改為依儀器出現情形分層的受限置換（仍符合「BH 數固定、同一標籤」）。
2. **程式錯誤**：單一儀器時分層出錯，已修正，統計量不變。散點抖動改用 crc32 種子。
3. **計算資源**：OneDrive 佔用約 10 GB RAM，特徵計算的平行數由 4 降為 2，結果不受影響。
