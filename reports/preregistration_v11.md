# v11 預先設定：在從未用過的 NICER 觀測上，以凍結的管線與模型做前瞻性檢驗

撰寫：2026-10-06 約 01:50，**在看過 v1–v10 全部結果之後**，在下載任何 v11 資料、計算任何 v11 特徵或模型之前。
起因：使用者「merge and continue v11 at 1:40 am」（v10 已合併，PR #8）。本設定由我撰寫並自行核准（同 v5–v10）。
版本：v11。分支 `v11-analysis`（自 master `793a644`）。
`config.py`：v4–v7、v9、v10 區塊條件擴充到 v11，新增 v11 區塊；v1–v10 的設定值不變（已逐一比對）。

## 0. 為什麼這樣設計（獨立性的上限）
- v10 的兩個合併結果（硬態時間增益 +0.145 [+0.028, +0.257]；同顏色下 ν_c 低 0.37 dex，p = 0.0012）的假說來自 v5–v9，**不是獨立確認**。
- **新的 BH 天體已用盡**：Marcel+2026 的 25 個確認 BH 中，RXTE＋NICER 已用了 16 個。其餘多在寧靜態、早於 RXTE，或沒有可用的 X 光計時資料。Insight-HXMT 的資料對外開放（IHEP 公告；資料入口 hsuc.ihep.ac.cn），但是否需要註冊、能否以腳本批次下載，本次**未能查證**；AstroSat 也未查證。依規則記錄下來，本版不採用。
- 因此 v11 能做到的最大獨立性是**觀測層級的前瞻性檢驗**：
  - 同一批 NICER 天體，**從未下載、從未讀過**的觀測（排除 v9 試過的全部 792 筆）；
  - 特徵管線、能態門檻、模型完全凍結；
  - 每個天體只用「訓練時排除該天體」的模型（out-of-source）去預測它的新觀測。
- **另外**：NICER 上從未用過的天體（只有 1–4 筆合格觀測者，共 7 個 NS 與 XTE J1859+226），這是天體層級獨立的資料，但幾乎只有 NS，只能檢驗誤報率。
- **限制先寫明**：天體與 v10 相同，所以 v11 檢驗的是「這個關係能否推廣到同一批天體在其他時間的觀測」，而不是「能否推廣到新天體」。

## 1. 共同規則（同 v7–v10）
- Bootstrap 2000 次、seed 42、BH／NS 分層。
- 區間不含 0（置換檢定則 p < 0.05）才寫「有差異」，否則寫「未偵測到」。
- 每個子分析一個 ★ primary。
- 變更記入 decision_log。
- 報告用繁體中文。

## 2. 資料（`55_v11_select.py`、`56_v11_fetch.py`）
- **v9 天體**（`data/v9/sources.csv` 中 included 的 66 個）：
  - 合格觀測：`nicermastr` 目標座標 ≤ 0.05°、exposure ≥ 1000 s，且**不在 v9 試過的 792 筆內**。
  - 依時間排序分成 8 段，每段以 `default_rng(SEED + 1000 + 位置)` 排序，最多試 3 筆。
- **從未用過的天體**：`data/v9/sources.csv` 中未納入、非重疊視野、有 1–4 筆合格觀測者，全部觀測都試。
- **下載**：從 HEASARC AWS 鏡像以 64 MB range 請求串流，到檔尾或 1 GB 為止（同 v10）。**原始位元組不存檔**（磁碟剩 64 GB），只記錄 URL、bytes、SHA256 與檔案大小（`logs/downloads.jsonl`）；之後可以用腳本重新下載重現。
- **特徵**：`v9lib.obs_features` 的完整管線，凍結不變：
  - 2–10 keV、128 s 段、MPU 全配對 cospectrum、ratio of means、v4 爆發規則；
  - 品質規則：≥ 3 段、≥ 20 c/s；能態門檻同 v7a；
  - 另外輸出 13 個 log bin 的標準誤（給 Lorentzian 用）與 12–15 keV 背景比。
- **健全性（IC2）**：新觀測中，Cyg X-2＋GX 17+2 ≥ 2/3 為軟態類。不通過 → v11a／v11b 停止並回報。

## 3. 凍結的模型與規則（`57_v11_analysis.py`）
- **IC1**：在 v10 的 NICER 整筆特徵上重做 LOSO，預測必須與 `results/v10a/v10_nicer_full_oof.csv` 完全相同（最大差 < 1e-9）。
- 每個 v10 天體 s，凍結模型＝在 v10 NICER 資料上**排除 s** 後擬合的 H_N-LR、H_N+T_N-LR（以及 RF 版本）。用它預測 s 的新觀測。
- 從未用過的天體：用全部 v10 NICER 資料擬合的模型。
- **凍結的簡單規則**：ν* ＝ v10 NICER 硬態類觀測中，BH 的 ν_c 中位數與 NS 的 ν_c 中位數的幾何平均（在看 v11 資料前算出並寫入 log）。觀測層級：硬態類且 ν_c < ν* → BH。天體層級：該天體的新硬態類觀測中，判為 BH 者 ≥ 一半 → BH。

## 4. v11a ★：前瞻性的硬態時間增益
- 新觀測中的硬態類（凍結門檻），觀測層級 AUC：**凍結 H_N+T_N-LR − 凍結 H_N-LR**。
- 區間：在新觀測樣本的全部天體上做 BH／NS 分層重抽（v7a 方式）。
- 可檢定條件：新硬態類中 BH、NS 天體各 ≥ 3。
- 描述性：
  - RF 版本；
  - 軟態類；
  - 來源層級；
  - 凍結規則的敏感度與特異度；
  - 依 BH 天體逐一移除的影響分析。

## 5. v11b ★：前瞻性的特徵頻率差
- 新觀測中、硬態類、ν_c 有值者。方法同 v9b／v10b 的 NICER 部分：log₁₀ ν_c 對標準化 [c1, c2] 做不看標籤的 kNN 殘差化（k = 25，留一天體，只在新資料內），取天體平均。
- D = BH 平均 − NS 平均；在新資料的天體上置換標籤 20000 次（seed 42），雙尾 p。p < 0.05 → 有差異。
- 描述性：
  - **亮度控制**：殘差化變數加入 log 計數率，即 [c1, c2, log rate]；在新資料與 v10 資料各做一次。這是觀測亮度的代理，**不是 Eddington 比**。
  - 依 BH 天體逐一移除。

## 6. v11c（描述性）：Lorentzian 特徵頻率
- 新硬態類觀測的 13 個 log bin 分數變異（含標準誤）。
- 擬合 1 個與 2 個零中心 Lorentzian（每 bin 的積分功率＝r²·(2/π)·[atan(b/Δ) − atan(a/Δ)]，Δ 限制在 1/128–128 Hz），用加權最小平方。BIC 改善 > 6 時採用 2 個。
- 取最低頻 Lorentzian 的寬度 ν_L 作為「斷點」頻率。log₁₀ ν_L 用 v11b 同樣的顏色條件置換比較 BH 與 NS。

## 7. v11d（描述性）：從未用過的天體

## 9. 已知限制（事先寫明）
1. **寫於看過 v1–v10 之後**。檢驗的假說來自先前結果，但資料（觀測）是新的，模型與管線是凍結的。
2. 天體與 v10 相同，因此不是天體層級的獨立確認。同一天體不同時間的觀測可能相關（例如同一次爆發）。從未讀過的觀測可能與已用觀測同屬一次爆發的不同日子。
3. 沒有做 Eddington 比控制：MINBAR source table 沒有距離欄位，要逐源查證約 60 個天體的距離，這次無法完成。只用觀測計數率作為亮度代理。
4. 原始位元組不存檔，但可以用腳本與記錄的 URL、SHA256 重新下載驗證。
5. NICER 未扣背景（同 v9／v10）。
